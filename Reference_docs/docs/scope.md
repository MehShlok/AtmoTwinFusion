# Scope

*Living document — last updated 2026-10-18.*

## In scope
- Corrected Python port of the MATLAB code (done) and its reuse as the Pin-GTSVM engine.
- ImageNet-C, two 20-class sets (Similar-20, Dissimilar-20), 15 standard corruptions × 5 severities, split 70/30 by
  source image.
- Several ViTs (chosen in Task 4): frozen pretrained features **and** a fine-tuned variant.
- Pin-GTSVM-RBF, one-vs-one within each set (190 pairs per set); scalable solver for search, exact solver for validation.
- Baselines: hinge-loss TWSVM (τ = 0), a standard SVM, a linear probe and kNN on the same features.
- A held-out corruption-family test next to the standard 70/30 test.
- Metrics per corruption × severity; statistical comparison of τ > 0 vs τ = 0; Similar-20 vs Dissimilar-20.
- 2D/3D representations with quantitative faithfulness measures (Task 3).
- Research reviews: best ViTs for ImageNet-C (Task 4) and work that challenges the approach (Task 5).
- A config-driven experiment framework (matrix, feature cache, run registry, selection report) and edge metrics.

## Out of scope (unless the user decides otherwise)
- Training ViTs from scratch.
- 100 or 1,000 classes (reduced to 20 + 20 to save compute).
- Comparison with published ImageNet-C mCE leaderboards (our protocol trains on ImageNet-C; not comparable).
- The 4 "extra" ImageNet-C corruptions (default: the 15 benchmark corruptions only).
- Parking datasets (PKLot, CNRPark, Hazy). The port's parking configs stay as the Task 1 deliverable but are not run.
- Dehazing / image restoration.

## Constraints
- Local: 16 GB RAM, RTX 3050 4 GB; **drive C: nearly full (~2.9 GB free)** → every download, cache and output goes to D:.
- **All code runs on Kaggle** (GPU quota 30 h/week, sessions ≤ 12 h); the user's PC is not used for running code.
  ImageNet-C is not downloaded locally.
- Exact Pin-GTSVM: ~6–11 s per pair (measured, `results/benchmarks/`); 380 pairs ≈ 38–70 min per setting.

## Class sets (approved 2026-10-13)
Files: `study/configs/class_sets/similar20.json`, `study/configs/class_sets/dissimilar20.json`, generated by
`study/scripts/select_classes.py` (a test re-runs the selection and requires identical output).
Procedure (model-independent, deterministic; ties broken by WordNet ID):
1. **Similar-20:** most specific WordNet 3.0 nodes holding ≥ 20 ImageNet-1k classes; inside each, drop the class least
   similar to the rest until 20 remain; pick the node with the highest mean Wu-Palmer similarity. Wu-Palmer is computed
   on the WordNet graph with the deepest shared ancestor (nltk's built-in version picks a shallower one for dog breeds
   because "dog" is also a "domestic animal", which gave two terriers a lower score than go-kart vs. semi-trailer).
   Result: **terrier** (26 classes → 20). All 20 lie inside the BREEDS "dog" group. Left out: Staffordshire
   bullterrier, American Staffordshire terrier, wire-haired fox terrier, Lakeland terrier, Sealyham terrier, miniature schnauzer.
2. **Dissimilar-20:** farthest-first traversal (Gonzalez 1985) on 1 − Wu-Palmer similarity over the **BREEDS**
   hierarchy (visually calibrated; a true tree; covers 890 of 1,000 classes — it omits ambiguous ones), excluding all
   dogs, with no two classes sharing a level-4 BREEDS group.
